int ailiaSpeechVadBuffered(
  1. Pointer<AILIASpeech> net,

Determines whether the end of an utterance has been detected by VAD.

Parameters:

  • net: A network instance pointer
  • buffered: Is detected (1 : Detected, 0 : Not Detected)

Returns:

If this function is successful, it returns AILIA_STATUS_SUCCESS , or an error code otherwise.

Unlike ailiaSpeechBuffered, this function does not return 1 just because 30 seconds worth of data has been accumulated. It returns 1 only when speech of speech_sec or longer is followed by silence of no_speech_sec or longer. Use this function to recognize audio per utterance, such as waiting for voice commands. Silence before the utterance and noise shorter than speech_sec are discarded, so speech after a long silence is recognized from its beginning. It also returns 1 without a boundary after ailiaSpeechFinalizeInputData is called. While speech continues, data is accumulated until a boundary is detected. Since ailiaSpeechTranscribe processes at most 30 seconds per call, speech longer than 30 seconds is processed by calling ailiaSpeechTranscribe repeatedly while this function returns 1. To limit the accumulated length, check the number of unprocessed frames with ailiaSpeechGetPosition. The detection threshold must be set in advance using ailiaSpeechSetSilentThreshold. When 1 is returned, call ailiaSpeechTranscribe.
