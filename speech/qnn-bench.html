ailia Speech NPU（QNN）ベンチマーク

ailia Speech の QNN バックエンドで Whisper を Qualcomm SoC の NPU で実行した測定結果を示します。

QNN バックエンドの使い方は ailia Speech NPU（QNN）ガイド を参照してください。

  • Android（Snapdragon 8+ Gen 1 / SM8475、Snapdragon 7s Gen 3 / SM7635）
  • Windows（Snapdragon X Plus / SC8380XP、QCS6490）

Android

測定条件

Whisper Medium と Large V3 Turbo を 2 機種で測定した結果です。Snapdragon 8+ Gen 1（SM8475 / Hexagon v69）と Snapdragon 7s Gen 3（SM7635 / Hexagon v73）を使用しています。NPU は各 SoC 向けの INT16 の QNN Model、CPU は同じ端末上で元の ONNX モデルを ailia SDK の CPU 経路で実行した値です。CPU / NPU とも同じランタイムを使用しています。

  • 音声は約 39.7 秒の日本語音声（48 kHz、ステレオ、PCM16）で、全機種で同じファイルを使用しています。
  • 言語は自動判定、タスクは transcribe、greedy デコード（beam size 1）、VAD・話者分離なし、CPU スレッド数は AUTO です。
  • 各経路でモデルを一度開き、1 回のウォームアップ後の 3 回を集計しています。モデルのオープン、WAV 読み込み、入力の push、ウォームアップは含みません。
  • 処理時間と CPU 時間は同じ ailiaSpeechTranscribe 呼び出し区間で計測しています。

Windows

測定条件

Windows ARM64 の 2 機種で、Android と同じ音声・同じ手順・同じ集計方法で測定した結果です。Snapdragon X Plus（SC8380XP / Hexagon v73、8 コア）は Windows 11 Pro、QCS6490（Hexagon v68、8 コア）は Windows 11 IoT Enterprise LTSC を使用しています。NPU は各 SoC 向けの INT16 の QNN Model、CPU は同じ端末上で元の ONNX モデルを ailia SDK の CPU 経路で実行した値です。
