ailia Speech NPU（QNN）ガイド

ailia Speech の QNN バックエンドを使用して、Qualcomm SoC の NPU で Whisper による音声認識を高速に実行する方法を説明します。

概要

ailia Speech 1.6.0 以降は、Qualcomm SoC の NPU（Hexagon）を使用した Whisper の推論に対応しています。NPU を使用することで、高速・低消費電力に音声認識を実行できます。

QNN（Qualcomm AI Engine Direct）は Qualcomm が提供するバックエンド API です。ailia Speech では、Whisper のエンコーダとデコーダを SoC 専用の QNN Model（.qnn）に変換したファイルを使用します。1 つの .qnn にエンコーダとデコーダの両方が含まれているため、端末には ONNX は不要で、.qnn のみを配置します。

QNN Model（.qnn）
SoC 固有の Context Binary（エンコーダ + デコーダ）
↓
ailia Speech（Device）
Open 時にエンコーダ・デコーダとして同じ .qnn を指定
↓
Hexagon NPU
QNN（HTP バックエンド）でエンコーダ / デコーダを実行
注意: QNN Model（.qnn）の読み込みは ailia Speech 1.6.0 以降で利用できます。

対応プラットフォーム

  • Android（Snapdragon 8+ Gen 1 / sm8475、Snapdragon 7s Gen 3 / sm7635）
  • Windows on Arm（Snapdragon X Plus / sc8380xp）
  • QCS6490（qcs6490）

QNN Model は SoC ごとに別ファイルになります。端末の SoC に一致する .qnn を使用してください。異なる SoC 向けのモデルは流用できません。

注意: QNN（QAIRT）の対応バージョンは ailia SDK と同じ 2.47.0.260601 です。QNN Model は QNN SDK のバージョンにも依存するため、異なるバージョンの QNN ランタイムと組み合わせないでください。

対応モデル

現在は Whisper Large V3 Turbo と Whisper Medium に対応しています。いずれも Int16 に量子化したモデルです。

プロジェクト設定

QNN ランタイムの取得と配置は ailia SDK と共通です。Android の AndroidManifest.xml と build.gradle の設定、Windows on Arm での QNN DLL と NPU 側の .so / .cat の配置は ailia SDK の QNN セットアップを参照してください。QNN ランタイムはモデル生成時と同じ QAIRT 2.47.0.260601 を使用してください。

Android では .qnn は assets 内のパスを直接指定できません。初回起動時にアプリのプライベートストレージへコピーするかダウンロードし、その実ファイルパスを以下の API に渡してください。

コードサンプル：モデルのオープン

通常は Open 時にエンコーダとデコーダの ONNX をそれぞれ指定しますが、QNN Model を使用する場合は、エンコーダとデコーダの両方に同じ .qnn のパスを指定します。モデルタイプには .qnn の元になったモデル（Large V3 Turbo または Medium）を指定します。以降の文字起こしの API は ONNX を使用する場合と同じです。

C

#include "ailia_speech.h"
#include "ailia_speech_util.h"

const char *qnn_path = "/data/user/0/your.package/files/whisper-large-v3-turbo-sm7635-int16.qnn";

struct AILIASpeech *speech = NULL;
ailiaSpeechCreate(&speech, env_id, AILIA_MULTITHREAD_AUTO, memory_mode,
                  AILIA_SPEECH_TASK_TRANSCRIBE, AILIA_SPEECH_FLAG_NONE,
                  ailiaSpeechUtilGetCallback(), AILIA_SPEECH_API_CALLBACK_VERSION);
/* エンコーダとデコーダに同じ .qnn を指定する */
ailiaSpeechOpenModelFileA(speech, qnn_path, qnn_path,
                          AILIA_SPEECH_MODEL_TYPE_WHISPER_MULTILINGUAL_LARGE_V3_TURBO);

Unity（C#）

using System.IO;
using UnityEngine;
using ailiaSpeech;

string qnnPath = Path.Combine(Application.persistentDataPath, "whisper-large-v3-turbo-sm7635-int16.qnn");
var speech = new AiliaSpeechModel();
// エンコーダとデコーダに同じ .qnn を指定する
speech.Open(qnnPath, qnnPath, envId, memoryMode,
            AiliaSpeech.AILIA_SPEECH_MODEL_TYPE_WHISPER_MULTILINGUAL_LARGE_V3_TURBO,
            AiliaSpeech.AILIA_SPEECH_TASK_TRANSCRIBE,
            AiliaSpeech.AILIA_SPEECH_FLAG_NONE, "auto");

Flutter

import 'package:ailia_speech/ailia_speech.dart';

const qnnPath = '/data/user/0/your.package/files/whisper-large-v3-turbo-sm7635-int16.qnn';
final speech = AiliaSpeechModel();
// エンコーダとデコーダに同じ .qnn を指定する
await speech.open(
  encoderFile: qnnPath,
  decoderFile: qnnPath,
  modelType: AILIA_SPEECH_MODEL_TYPE_WHISPER_MULTILINGUAL_LARGE_V3_TURBO,
);

JNI（Kotlin）

context は Android の Activity または Application の Context です。

val qnnPath = "${context.filesDir}/whisper-large-v3-turbo-sm7635-int16.qnn"
val speech = AiliaSpeech(
    envId = -1,
    task = AiliaSpeech.AILIA_SPEECH_TASK_TRANSCRIBE,
    flags = AiliaSpeech.AILIA_SPEECH_FLAG_NONE,
)
// エンコーダとデコーダに同じ .qnn を指定する
speech.openModel(qnnPath, qnnPath,
    AiliaSpeech.AILIA_SPEECH_MODEL_TYPE_WHISPER_MULTILINGUAL_LARGE_V3_TURBO)

評価版アプリ

Android 向けの評価版 APK は ailia-models-kotlin-qnn.apk です。Snapdragon 8+ Gen 1（sm8475）または Snapdragon 7s Gen 3（sm7635）を搭載した端末で動作します。

Windows on Arm 向けの評価版アプリは ailia-models-flutter-qnn-v261026.zip です。Snapdragon X Plus もしくは QCS6490 で動作します。

制約

  • QNN Model は SoC ごとに変換が必要で、他の SoC 向けのファイルは使用できません。
  • 現在の対応モデルは Whisper Large V3 Turbo / Medium です。
