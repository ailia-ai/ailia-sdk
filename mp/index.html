ailia MotionPortrait

プリセットのアバターを試したり、好きな画像をドラッグ&ドロップして自分だけのアバターを生成し、表情・リップシンクアニメーションを再生できるライブラリです。

はじめに

プラットフォームを選び、最初のアニメーション生成を実行してみましょう。

1

インストール

サンプルプログラム mp-sample-js をクローンしてください。SDK mp-sdk-js は mp-sample-js プロジェクト内に submodule として含まれています。

サンプルプログラム SDK
2

実行

mp-sample-js フォルダで下記のコマンドを実行して、Web サーバーを立ち上げます。

python3 -m http.server 8000

Web ブラウザで http://localhost:8000/mpavatar にアクセスすることで、サンプルプログラムを実行可能です。ポート番号には 8000 番以外も指定可能です。

クローン不要で試したい場合は、公開中のサンプルサイトからブラウザだけで動作を確認できます。

サンプルサイト
1

インストール

サンプルプログラム mp-sample-unity をクローンした後、Unity 6.3 LTS (6000.3.16f1) 以降で開きます。SDK mp-sdk-unity は Package Manager 経由で自動的にダウンロードされます。

サンプルプログラム SDK
2

実行

mpSampleScene.unity のシーンを開き、Play してください。または、メニューバーの [File]-[Build Profiles] からビルドして実行してください。

1

インストール

サンプルプログラム mp-sample-kotlin をクローンしてサブモジュールを初期化し、Android Studio で開きます。SDK mp-sdk-kotlin は mp-sample-kotlin プロジェクト内に submodule として含まれています。

git clone https://github.com/ailia-ai/mp-sample-kotlin.git
cd mp-sample-kotlin
git submodule update --init --recursive
サンプルプログラム SDK
2

実行

Android 端末を USB で接続するか、エミュレータを起動し、Android Studio の Run ボタンからサンプルプログラムを実行してください。

動作環境

ailia MotionPortrait はブラウザおよびモバイル環境で動作します。

JavaScript

  • WebGL 対応の Web ブラウザ
  • HTTP サーバ経由での実行
  • インターネット接続のある環境

Unity

  • Windows 10 (バージョン 21H1 以降) / Windows 11
  • macOS Monterey (12.0) 以降
  • Linux (Ubuntu 22.04 / 24.04)
  • iOS 15 以上
  • Android 7.1 (API 25) 以上

Kotlin

  • Android 7.1 (API 25) 以上
  • Android Studio 2025.1.3 以降
  • Kotlin / Java (JNI)
