FRDM i.MX 95 Board Setup

How to connect the NXP FRDM i.MX 95, write the Linux image, boot and log in. For ailia SDK setup, see the NXP i.MX 95 Setup Guide.

Before using ailia SDK, boot the FRDM i.MX 95 and make sure you can log in from the serial console.

Board Setup

Required Equipment

In addition to the items included with the FRDM i.MX 95, prepare the following:

  • USB-C PD AC adapter: one that can supply 13.4V / 5A (67W). Retail adapters in the 100W class meet this.
  • Ethernet connection: required for pip installation and license download.
  • microSD card (about 32GB): for booting the latest Linux image.

Board Connections

Connector / switchUse
J25 (USB-C)Power. Connect to the AC adapter with the included power-capable Type-C to C cable.
J1 (USB-C)Debug USB serial. Connect to the PC with the included Type-C to A cable (cannot be used for power).
SW1 (DIP switch)Boot device. eMMC: SW1-1 ON / SW1-2 OFF; microSD: SW1-1 ON / SW1-2 ON
SW5 (slide switch)Power ON / OFF

USB Serial Settings

When the board is connected to a PC, four USB serial (CH344) COM ports appear. Open each port with Tera Term on Windows or minicom on Linux using the settings below. The login prompt appears on one of the four ports.

Speed: 115200
Data: 8 bit
Parity: none
Stop bits: 1

Boot and Login

Turning SW5 ON powers the board. The boot log is printed on the serial terminal. At the login prompt, log in as root (no password).

NXP i.MX Distro with Wayland and XWayland 6.18-wrynose imx95-15x15-lpddr4x-frdm ttyLP0

imx95-15x15-lpddr4x-frdm login: root

Preparing the Linux Image

The Linux image preinstalled on the eMMC is old. We recommend writing the latest BSP image based on Yocto Project 6.0 Wrynose to a microSD card and booting from it.

Writing to the microSD Card

Download the prebuilt image for the FRDM i.MX 95 (imx95-15x15-lpddr4x-frdm), imx-image-full-imx95-15x15-lpddr4x-frdm.rootfs.wic.zst, from Embedded Linux for i.MX (NXP).

Connect the microSD card to a Linux PC such as Ubuntu 22.04 via an SD card reader and check its device name. It is written as /dev/sdX below. Writing to the wrong device overwrites a disk on your PC, so check it carefully.

lsblk -p
zstdcat imx-image-full-imx95-15x15-lpddr4x-frdm.rootfs.wic.zst | sudo dd of=/dev/sdX bs=1M conv=fsync

After writing, set both SW1-1 and SW1-2 to ON and power on to boot from the microSD card. The image uses about 13GB.

Next Steps

Once you can log in to the board, install ailia SDK by following the NXP i.MX 95 Setup Guide.
