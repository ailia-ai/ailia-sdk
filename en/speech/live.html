ailia Speech Live Mode Guide

How to run low-latency speech recognition on microphone input using AILIA_SPEECH_FLAG_LIVE in ailia Speech.

Overview

With AILIA_SPEECH_FLAG_LIVE, speech recognition runs with low latency, without waiting for VAD or an audio segment boundary.

In normal mode, recognition does not run until 30 seconds of audio have accumulated or VAD detects a speech boundary. In Live mode, a tentative inference runs on the current buffer content even before a boundary is detected, and the result is passed to IntermediateCallback.

Note: Accuracy is higher without Live mode, because recognition can also refer to later audio. Do not use Live mode for audio files; use it for microphone input that needs real-time results.

How to Push PCM

When using AILIA_SPEECH_FLAG_LIVE, do not run the Buffered check and Transcribe after every PCM chunk you push. Instead, first push all PCM received so far, then run the Buffered check and Transcribe.

In Live mode, every Transcribe call runs a tentative inference over the whole current buffer. Running it per chunk makes inference fall behind the incoming audio, and latency keeps growing.

// NG: running the Buffered check and Transcribe for every chunk
while (mic_queue_pop(&chunk)) {
    ailiaSpeechPushInputData(speech, chunk.pcm, chunk.channels, chunk.samples, sample_rate);
    unsigned int buffered = 0;
    ailiaSpeechBuffered(speech, &buffered);
    if (buffered == 1) ailiaSpeechTranscribe(speech);
}

int intermediate_callback(void *handle, const char *text){
    printf("%s\n", text); // tentative result
    return 0; // return 1 to interrupt
}

ailiaSpeechCreate(&speech, env_id, AILIA_MULTITHREAD_AUTO, memory_mode,
                  AILIA_SPEECH_TASK_TRANSCRIBE, AILIA_SPEECH_FLAG_LIVE,
                  ailiaSpeechUtilGetCallback(), AILIA_SPEECH_API_CALLBACK_VERSION);
ailiaSpeechOpenModelFileA(speech, encoder_path, decoder_path,
                          AILIA_SPEECH_MODEL_TYPE_WHISPER_MULTILINGUAL_SMALL);
ailiaSpeechOpenVadFileA(speech, "silero_vad.onnx", AILIA_SPEECH_VAD_TYPE_SILERO);
ailiaSpeechSetIntermediateCallback(speech, &intermediate_callback, NULL);

while (recording) {
    // 1. Push all PCM received so far
    while (mic_queue_pop(&chunk)) {
        ailiaSpeechPushInputData(speech, chunk.pcm, chunk.channels, chunk.samples, sample_rate);
    }

    // 2. Then run the Buffered check and Transcribe
    while (true) {
        unsigned int buffered = 0;
        ailiaSpeechBuffered(speech, &buffered);
        if (buffered == 0) break;
        ailiaSpeechTranscribe(speech);

        unsigned int n;
        ailiaSpeechGetTextCount(speech, &n);
        for (unsigned int i = 0; i < n; i++) {
            AILIASpeechText text;
            ailiaSpeechGetText(speech, &text, AILIA_SPEECH_TEXT_VERSION, i);
            printf("%s\n", text.text);
        }
    }
}

Python

Each call to transcribe_step() pushes PCM, runs the Buffered check and runs Transcribe. So instead of calling transcribe_step() for every chunk received from the microphone, concatenate all PCM received so far and pass it to a single transcribe_step() call.

import numpy as np
import ailia_speech

def on_intermediate(text):
    print(text)  # tentative result

speech = ailia_speech.Whisper(flags=ailia_speech.AILIA_SPEECH_FLAG_LIVE,
                              callback=on_intermediate)
speech.initialize_model(
    model_path="./models/",
    model_type=ailia_speech.AILIA_SPEECH_MODEL_TYPE_WHISPER_MULTILINGUAL_SMALL,
)

while recording:
    # 1. Take all PCM received so far and concatenate it
    chunks = []
    while not mic_queue.empty():
        chunks.append(mic_queue.get())
    if not chunks:
        continue
    audio = np.concatenate(chunks)

    # 2. Pass it to transcribe_step once
    for result in speech.transcribe_step(audio, sample_rate, complete=False):
        print(result["text"])

JNI (Kotlin)

val speech = AiliaSpeech(
    envId = -1,
    task = AiliaSpeech.AILIA_SPEECH_TASK_TRANSCRIBE,
    flags = AiliaSpeech.AILIA_SPEECH_FLAG_LIVE,
)
speech.openModel(encoderPath, decoderPath,
    AiliaSpeech.AILIA_SPEECH_MODEL_TYPE_WHISPER_MULTILINGUAL_SMALL)
speech.setIntermediateCallback(object : IntermediateCallback {
    override fun onIntermediateResult(text: String): Int {
        Log.d("ailia", text) // tentative result
        return 0
    }
})

while (recording) {
    // 1. Push all PCM received so far
    while (true) {
        val chunk = micQueue.poll() ?: break
        speech.pushInputData(chunk.pcm, chunk.channels, chunk.samples, sampleRate)
    }

    // 2. Then run the Buffered check and Transcribe
    while (speech.getBuffered() == 1) {
        speech.transcribe()
        for (i in 0 until speech.getTextCount()) {
            Log.d("ailia", speech.getText(i).text)
        }
    }
}
