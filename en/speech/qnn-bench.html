ailia Speech NPU (QNN) Benchmark

Measurement results of running Whisper on the NPU of Qualcomm SoCs with the QNN backend of ailia Speech.

For how to use the QNN backend, see the ailia Speech NPU (QNN) Guide.

  • Android (Snapdragon 8+ Gen 1 / SM8475, Snapdragon 7s Gen 3 / SM7635)
  • Windows (Snapdragon X Plus / SC8380XP, QCS6490)

Android

Test conditions

Whisper Medium and Large V3 Turbo were measured on an ASUS AI2202 (Android 14) with Snapdragon 8+ Gen 1 (SM8475 / Hexagon v69). The NPU uses INT16 QNN Models (per-channel INT8 weights, U16 activations, U8 K/V cache). The CPU results run the original ONNX models through the ailia SDK CPU path on the same device. Both use the same runtime.

  • The input is about 39.7 seconds of Japanese speech (48 kHz, stereo, PCM16).
  • Automatic language detection, transcribe task, greedy decoding (beam size 1), no VAD or diarization, CPU threads set to AUTO.
  • Each path opens the model once, runs one warmup, then measures 3 runs. Model opening, WAV loading, input push and the warmup are excluded.
  • Processing time and CPU time are measured over the same ailiaSpeechTranscribe calls.

  • Realtime factor is audio duration / mean processing time; above 1x means the audio is transcribed faster than its length.
  • CPU usage is total process CPU time / total processing time / 8 cores × 100, where 100% means all 8 cores are fully used. It is the application process usage, not whole-device load or NPU usage.

The NPU is about 10.5x faster than the CPU for Medium and about 27.6x faster for Large V3 Turbo. With Large V3 Turbo on the NPU, 39.7 seconds of audio is transcribed in about 3.2 seconds, more than 12x realtime. CPU usage stays around 8–9%, leaving CPU headroom for the application.

Recognition results

Because the CPU and NPU use different quantization formats, the output text may not match exactly. For this audio, Large V3 Turbo produced identical text on CPU and NPU after removing punctuation and spaces. Medium on the NPU added punctuation and differed in a few words. This is not a WER / CER evaluation against a reference transcript.
