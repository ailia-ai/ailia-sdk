FRDM i.MX 95 ボードセットアップ

NXP FRDM i.MX 95 の接続、Linux イメージの書き込み、起動とログインの手順を説明します。ailia SDK のセットアップは NXP i.MX 95 セットアップガイド を参照してください。

ailia SDK を使用する前に、FRDM i.MX 95 を起動してシリアルコンソールからログインできる状態にします。

ボードのセットアップ

必要な機材

FRDM i.MX 95 の付属品に加えて、以下を用意します。

  • USB-C PD 対応 AC アダプター: 13.4V / 5A (67W) を供給できるもの。量販店では 100W クラスのアダプターが該当します。
  • Ethernet 接続: pip によるインストールとライセンス取得に必要です。
  • microSD カード (32GB 程度): 最新の Linux イメージから起動する場合に使用します。

ボードの接続

コネクタ / スイッチ用途
J25 (USB-C)電源。付属の電源供給対応 Type-C to C ケーブルで AC アダプターと接続します。
J1 (USB-C)デバッグ用 USB シリアル。付属の Type-C to A ケーブルで PC と接続します (電源供給には使用できません)。
SW1 (DIP スイッチ)ブートデバイス選択。eMMC: SW1-1 ON / SW1-2 OFF、microSD: SW1-1 ON / SW1-2 ON
SW5 (スライドスイッチ)電源 ON / OFF

USB シリアルの設定

PC にボードを接続すると、USB シリアル (CH344) の COM ポートが 4 つ認識されます。Windows では Tera Term、Linux では minicom などで各ポートを開き、次の設定にします。ログインプロンプトは 4 つのうち 1 つのポートに表示されます。

Speed: 115200
Data: 8 bit
Parity: none
Stop bits: 1

起動とログイン

SW5 を ON にすると電源が入り、シリアルターミナルにブートログが表示されます。ログインプロンプトが表示されたら root でログインします (パスワードなし)。

NXP i.MX Distro with Wayland and XWayland 6.18-wrynose imx95-15x15-lpddr4x-frdm ttyLP0

imx95-15x15-lpddr4x-frdm login: root

Linux イメージの準備

出荷時に eMMC へ書き込まれている Linux イメージは古いため、Yocto Project 6.0 Wrynose ベースの最新 BSP イメージを microSD カードへ書き込み、microSD から起動することを推奨します。

microSD カードへの書き込み

Embedded Linux for i.MX (NXP) から FRDM i.MX 95 (imx95-15x15-lpddr4x-frdm) 向けのビルド済みイメージ (imx-image-full-imx95-15x15-lpddr4x-frdm.rootfs.wic.zst) をダウンロードします。

Ubuntu 22.04 などの Linux PC に SD カードリーダーで microSD を接続し、デバイス名を確認します。以下では /dev/sdX と記載しています。デバイス名を誤ると PC のディスクを上書きするため、必ず確認してください。

lsblk -p
zstdcat imx-image-full-imx95-15x15-lpddr4x-frdm.rootfs.wic.zst | sudo dd of=/dev/sdX bs=1M conv=fsync

書き込み後、SW1 を両方 (SW1-1、SW1-2) ON にして電源を入れると microSD から起動します。イメージは約 13GB を使用します。

次のステップ

ボードにログインできたら、NXP i.MX 95 セットアップガイド に従って ailia SDK をインストールしてください。
