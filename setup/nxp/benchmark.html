NXP i.MX 95 ベンチマーク

NXP FRDM i.MX 95 で、ailia SDK (NXP NPU 対応版) と NXP ONNX Runtime の CPU・NPU 実行を比較したベンチマークの詳細です。結果の概要とセットアップ手順は NXP i.MX 95 セットアップガイド を参照してください。

測定条件

FRDM i.MX 95 で、ailia SDK (NXP NPU 対応版) と NXP BSP 同梱の ONNX Runtime 1.24.3 (ORT) を比較しました。ViT-B/16 は 2026-11-18、その他のモデルは 2026-11-20 に測定しています。ailia のランタイムのリビジョンは各モデルの節に記載しています。いずれも CPU 6 スレッド、プロファイル無効で、NPU の値は非対応レイヤーの CPU 実行を含みます。モデルは各方式で同じものを使用しています。

ViT-B/16 (画像分類、224×224)

2026-11-18 測定。定数重みの MatMul を MatMulNBits INT4 に変換し、その他の演算を FP32 で実行するモデルです。CPU 6 スレッド、プロファイル無効で 10 回測定した推論時間の中央値です。モデル Open 後のダミー推論 1 回と、実入力による 3 回のウォームアップは測定から除外しています。

「出力変動」は、同じ入力を繰り返し推論したときの出力の最大絶対差です (0 は毎回同じ結果)。ailia NPU は ORT NPU の約 1.23 倍の速度です。全条件・全測定で Top-1 は 208 でした。ORT NPU のみ、同じ入力でも出力値の変動 (最大絶対差 0.2002) を観測し、他の 3 条件では変動はありませんでした。

SAM 2.1 Tiny (セグメンテーション、512×512)

2026-11-20 にランタイム ac22f5086 で測定。ailia-sdk-nxp-demo の COCO 校正済みモデル coco-val2017-v1 を使用し、ailia の CPU 実行には NEON 最適化した整数 MatMul を使用しています。全方式でモデル Open 時に同じダミー入力で 1 回推論し、その後 Bedroom の 5 フレームを同じ 2 点で 1 周ウォームアップしました。続く 3 回の中央値で、ウォームアップは測定に含みません。

モデル別は 1 回あたりの平均時間の中央値です。全体時間は画像読み込み・前後処理を含み、モデル読み込み・描画・保存を除きます。4 方式とも同じモデルを使用します。NPU 方式では Image Encoder と Memory Attention を CPU / NPU 混在で実行し、その他は CPU 実行です。

※ ORT NPU は以前の測定で追跡マスクの異常 (後続フレームのマスクが 0〜3 画素) を確認しているため、速度参考値です。今回の速度測定は精度の確認を兼ねていません。

Bedroom での FP32 参照に対する平均マスク IoU は、ホスト ORT CPU で 96.07%、実機 ailia NPU で 95.71% です。正解マスクに対する精度ではありません。

Grounding DINO Swin-T (オープン語彙物体検出、400×599)

2026-11-20 にランタイム c97d853c4 (と整数演算の融合・パックの改良) で測定。COCO 校正済みモデル grounding-coco-val2017-dql-v2 を使用し、入力画像はデモ同梱の images/grounding_dino/demo.jpg、プロンプトは Horse. Clouds. Grasses. Sky. Hill. です。モデル Open 時のダミー推論 1 回を除外し、続く 3 回の中央値を示します。モデル読み込みと前後処理は含みません。

項目ORT CPUORT NPUailia CPUailia NPU
推論時間 (中央値)7,654.0 ms7,626.0 ms8,926.2 ms4,053.6 ms

4 方式とも馬を検出しました (検出精度のベンチマークではなく動作確認です)。ailia NPU では固定重みの MatMul 347 個を NPU で実行します。両入力が動的な MatMul 109 個は DynamicQuantizeLinear + MatMulInteger として明示的に量子化しており、行列が小さいため CPU の NEON 整数演算で実行します。Attention を明示的に量子化する前のモデルと比べて、馬の検出 7 個は維持され、検出枠の IoU は平均 0.986 でした。ORT NPU は推論ごとに出力が変動することがあります。

Depth Anything V2 Metric Depth Small (屋内深度推定、518×518)

2026-11-20 にランタイム c97d853c4 で測定。COCO 校正済みモデルを使用し、入力は Bedroom の 1 フレーム目 (00000.jpg) です。モデル Open 時のダミー推論 1 回を除外し、続く 3 回の中央値を示します。モデル読み込み・前処理・描画は含みません。

項目ORT CPUORT NPUailia CPUailia NPU
推論時間 (中央値)3,150.0 ms3,093.7 ms※3,381.8 ms2,693.5 ms

ailia NPU は固定重みの MatMul 48 個に加えて、Attention の MatMul 24 個も NPU で実行します。Attention の MatMul は、両入力を DynamicQuantizeLinear で量子化した MatMulInteger としてモデル内で明示しています。ORT は固定重みの MatMul のみを NPU で実行する構成です。

※ ORT NPU は Neutron のメモリ確保に失敗して CPU にフォールバックしたため、NPU の測定値ではありません。

この画像では、ailia CPU と ailia NPU の出力は一致しました。同じモデルの ORT CPU の出力との差は平均 2.93 cm (最大 51.71 cm) です。Attention を量子化していない以前のモデルとの差は平均 33.83 cm (最大 135.63 cm) あり、量子化が深度推定値に影響します。いずれも出力どうしの比較で、正解深度に対する精度ではありません。

YOLOX-S (物体検出、320×320)

2026-11-20 にランタイム ac22f5086 で測定。COCO 校正済みの INT8 モデル (ConvInteger 83 個) を使用し、バッチ 1、入力画像はデモ同梱の images/yolox/input.jpg です。モデル Open 時のダミー推論 1 回を除外し、続く 10 回の中央値を示します。前処理・NMS・描画は含みません。

項目ORT CPUORT NPUailia CPUailia NPU
推論時間 (中央値)794.0 ms794.3 ms435.4 ms114.9 ms
FPS1.261.262.308.70

CPU の値は最適化した FP32 モデルではなく、同じ ConvInteger モデルの値です。ailia の CPU 実行は、固定重みをキャッシュするタイル分割の NEON INT8 カーネルを使用します。ORT の Neutron EP では ConvInteger が CPU で実行されるため、ORT NPU は ORT CPU とほぼ同じ時間です。ailia NPU は、対応する演算の出力の再量子化を NPU 上で行います。CPU 実行とは丸め方が異なるため、出力は CPU 実行とビット単位では一致しません。

COCO val2017 全 5,000 枚での AP は、FP32 (ホスト ORT CPU) の 30.42 に対し、INT8 (ailia NPU) で 29.00 (-1.42 ポイント) です。評価に使用した画像は校正データと同じため、独立したテストセットでの精度ではありません。
