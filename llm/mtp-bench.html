ailia LLM MTP ベンチマーク

ailia LLM 1.5.1 の MTP（Multi-Token Prediction）を使用した、Qualcomm SoC の NPU と CPU における Gemma 4 の測定結果です。

MTP の仕組みと使い方は ailia LLM MTP ガイド を参照してください。

  • Android
    • Snapdragon 8+ Gen 1（SM8475）：E2B
    • Snapdragon 7s Gen 3（SM7635）：E2B / E4B
  • Windows
    • Snapdragon X Plus（SC8380XP）：E2B / E4B
    • QCS6490：E2B

Android

測定条件

  • NPU：v1.5.1 の MTP 対応モデル（W4）、QAIRT 2.47、コンテキスト長 8192、AR-256（Prefill）/ AR-4（検証）/ AR-1 構成です。
  • CPU：llama.cpp で実行しています（スレッド数 4）。本体は GGUF（E2B は Q4_K_M、E4B は QAT Q4_0）、Assistant は Q4_0 の GGUF です。
  • MTP：「MTP あり」は Assistant を開いた値（ドラフト長 3）です。受理率は、Assistant の候補が本体の検証で採用された割合です。
  • 測定方法：greedy で、各条件 2 回の中央値です。Decode は 81 トークン入力・1,000 トークン生成、Prefill は 64〜2,048 トークン入力・1 トークン生成です。
  • 画像・音声入力：画像は 768x768 の 1 枚（100 トークン出力）、音声は英語音声 1 件の書き起こし（32 トークン出力）です。TTFT はエンコーダを含み、モデルのオープンは含みません。
  • CPU 使用率：Decode 中のプロセス CPU 使用率で、8 コアすべてを使い切った状態を 100% とします。CPU は 4 スレッドで動作するため 50% 前後になります。

Windows

測定条件

  • OS：SC8380XP は Windows 11 Pro、QCS6490 は Windows 11 IoT Enterprise LTSC です。
  • NPU：v1.5.1 の MTP 対応モデル（SC8380XP は FP16 / W4、QCS6490 は Int16）、QAIRT 2.47、コンテキスト長 8192 です。
  • CPU / GPU：CPU は llama.cpp で実行しています（OpenMP 無効、高性能コアの 4 コア）。本体は QAT Q4_0、Assistant は Q4_0 の GGUF です。GPU は SC8380XP の Adreno X1-45 で llama.cpp の OpenCL バックエンドを使用しています（QCS6490 は未測定）。
  • 測定方法：greedy で、各構成 1 回の測定です。Decode・Prefill・受理率の条件は Android と同じです。
  • 画像・音声入力：画像は 768x768 の 1 枚（100 トークン出力）、音声は英語音声 1 件の書き起こし（33 トークン出力）です。エンコーダは CPU・GPU の構成では CPU、NPU の構成では NPU で実行しています。
  • CPU 使用率：Decode 中のプロセス CPU 使用率で、8 コアすべてを使い切った状態を 100% とします。CPU は高性能コアの 4 コアだけを使用するため 50% 前後になります。
