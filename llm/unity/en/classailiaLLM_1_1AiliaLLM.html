◆ ailiaLLMSetTools()

static int ailiaLLM.AiliaLLM.ailiaLLMSetTools ( IntPtr  llm,
IntPtr  tools_json 
)

Set the tool (function) definitions.

Parameters
llmA LLM instance pointer
tools_jsonOpenAI-compatible JSON array of tool definitions (UTF-8, null terminated). IntPtr.Zero clears the tools.
Returns
If this function is successful, it returns AILIA_LLM_STATUS_SUCCESS , or an error code otherwise.

Tools are defined in the same format as the tools parameter of the OpenAI Chat Completions API. They are rendered into the prompt through the chat template on the next ailiaLLMSetPrompt, and the output is constrained by a grammar for the tool call syntax. Parse the raw output with ailiaLLMGetResponseJson. While tools are set, the content of role "assistant" is the raw output and the content of role "tool" is the tool result. Legacy prompt APIs reject tool use. Use SetPromptJson/GetResponseJson instead.
